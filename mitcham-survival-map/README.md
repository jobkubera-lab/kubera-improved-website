# Kubera Park & Local Intelligence — Mitcham and Merton

One mobile-first civic-technology prototype combining the original Mitcham Survival Map, verified park intelligence and the Morden Hall Park Digital Discovery Trail proposal.

## Included

- 19 structured park records with field-level source, date, status and confidence metadata
- corrected fixed coordinates and official source links from merged PR #1
- useful Post Office, recycling and support locations
- working filters only; unknown facilities are not implied
- full park detail view with source links and verification dates
- responsive Leaflet map with resize and orientation recovery
- integrated Morden Hall Park trail prototype at `morden-hall-trail.html`
- PWA shell for same-origin core files

## Trust model

- Official or checked information is labelled separately from estimated coordinates.
- OpenStreetMap locations remain a community layer.
- Unconfirmed toilets, benches, bins, dog rules and parking display as “Not confirmed”.
- The Morden Hall trail is an independent proposal and requires National Trust review and written approval before production.

## Key sources

- Merton Council parks and open spaces
- National Trust Morden Hall Park visitor information
- Post Office branch finder
- OpenStreetMap and Overpass API
